Plotting
========

The :mod:`wcc_etc.plotting` module provides ready-made diagnostic plots in both
**matplotlib** and **bokeh**, plus a shared house style. Every plotting
function comes in a ``*_mpl`` and a ``*_bokeh`` variant.

Every figure on this page is generated by executing the code above it when the
documentation is built, so the plots always match the code that produced them.

The house style
---------------

Apply the shared theme once per session/notebook:

.. code-block:: python

   import wcc_etc
   wcc_etc.set_wcc_style()        # global matplotlib rcParams
   wcc_etc.WCC_STYLE              # the underlying rcParams dict

The style uses STIX math/text fonts, 150 dpi, inward ticks, and faint
gridlines on 1-D plots (image plots turn the grid off).

The example image
-----------------

The examples below all reuse the same simulated image — a G5V star on the
zodiacal background, imaged through ``sony:r``:

.. plot::
   :context: reset
   :nofigs:

   import matplotlib.pyplot as plt
   import wcc_etc
   from wcc_etc import (
       get_scene, ImageSimulator, AiryPSF, DefocusPSF, DEFOCUS_2WAVE_PATH,
       plot_image_mpl, plot_image_row_mpl, plot_radial_mpl,
       plot_encircled_energy_mpl,
   )

   wcc_etc.set_wcc_style()

   scene = get_scene("G5V", mag=12, background="zodi", bandpass="johnson_r")
   imsim = ImageSimulator.from_sensor_and_scene("sony:r", scene, npix=200)
   img = imsim.simulate(time=30, psf=AiryPSF(), add_noise=True, seed=0)

   # a much brighter star, to show the saturation overlay
   bright_scene = get_scene("G5V", mag=7, background="zodi", bandpass="johnson_r")
   bright_imsim = ImageSimulator.from_sensor_and_scene("sony:r", bright_scene, npix=200)
   bright_img = bright_imsim.simulate(time=30, psf=AiryPSF(), add_noise=True, seed=0)

The plots
---------

.. list-table::
   :header-rows: 1
   :widths: 28 72

   * - Function pair
     - What it shows
   * - ``plot_image_mpl`` / ``plot_image_bokeh``
     - A single image with equal x/y scale, a ``noise=`` toggle, and an
       optional ``show_saturation=`` mask overlay.
   * - ``plot_image_row_mpl`` / ``plot_image_row_bokeh``
     - A three-panel row: PSF+Noise / PSF (no noise) / saturation mask, on a
       shared color scale.
   * - ``plot_radial_mpl`` / ``plot_radial_bokeh``
     - The azimuthally-averaged radial profile with a half-width marker.
   * - ``plot_encircled_energy_mpl`` / ``plot_encircled_energy_bokeh``
     - The encircled-energy curve (normalized to 1) with an optional
       ``ee_target=`` marker.

A single image
~~~~~~~~~~~~~~

``show_saturation=True`` overlays the saturated pixels in red. The bright star
below drives the core well past the Sony full well:

.. plot::
   :context: close-figs

   plot_image_mpl(bright_img, show_saturation=True, units="mas")

A three-panel row
~~~~~~~~~~~~~~~~~

``plot_image_row_mpl`` puts PSF+noise, the noiseless PSF, and the saturation
mask side by side on a shared color scale — the quickest way to see what the
noise is doing to a given exposure:

.. plot::
   :context: close-figs

   plot_image_row_mpl(bright_img, units="mas")

.. plot::
   :context: close-figs

Encircled energy
~~~~~~~~~~~~~~~~

``ee_target=`` marks the radius enclosing a given fraction of the flux, which
is the aperture the SNR machinery is choosing between:

.. plot::
   :context: close-figs

   plot_encircled_energy_mpl(img, units="mas", ee_target=0.8)

Two ways to call them
---------------------

Each function accepts either a :class:`~wcc_etc.SimulatedImage` as the first
positional argument, **or** raw arrays via keywords
(``image_e=``, ``image_clean=``, ``saturation_mask=``, ``pixel_scale_mas=``).

Mind which array each helper reads: the 1-D helpers default to ``noise=False``
and therefore profile ``image_clean``, so that is the array to supply. Pass
``noise=True`` to profile the noisy ``image_e`` instead. The two track each
other through the core, where the signal is strong, and the noisy profile
scatters about the clean one further out as the per-annulus counts fall towards
the background:

.. plot::
   :context: close-figs

   # Raw arrays rather than a SimulatedImage, both branches on one axis.
   fig, ax = plt.subplots()
   plot_radial_mpl(
       image_clean=img.image_clean,
       pixel_scale_mas=img.pixel_scale_mas,
       units="mas",
       ax=ax,
       show_hwhm=False,
   )
   plot_radial_mpl(
       image_e=img.image_e,
       pixel_scale_mas=img.pixel_scale_mas,
       units="mas",
       noise=True,
       ax=ax,
       show_hwhm=False,
   )
   ax.lines[0].set_label("image_clean (noise=False)")
   ax.lines[1].set_label("image_e (noise=True)")
   ax.set_yscale("log")
   ax.legend()

Convenience methods on ``SimulatedImage``
-----------------------------------------

The image object dispatches to the functions above, with a ``backend=`` switch:

.. code-block:: python

   img.plot_image(backend="mpl", show_saturation=True)
   img.plot_image_row()                       # the 3-panel row
   img.plot_radial(units="mas")
   img.plot_encircled_energy(units="mas", ee_target=0.8)

.. plot::
   :context: close-figs

   img.plot_encircled_energy(units="mas", ee_target=0.9)

Return values and embedding
---------------------------

- The matplotlib variants return ``(fig, ax)`` (plus ``(x, y)`` data for the
  1-D plots), so you can pass an existing ``ax=`` and compose figures.
- The bokeh variants take ``return_="obj" | "html" | "components"``: use
  ``"obj"`` for ``bokeh.io.show()`` in a notebook, or ``"components"`` to get
  ``(script, div)`` for embedding in the Flask web portal.

.. code-block:: python

   # bokeh: components for a web template
   script, div = img.plot_image(backend="bokeh", return_="components")

Because the 1-D helpers hand back the profile they plotted, the returned
``(r, prof)`` is what you use to build a labelled overlay — here an in-focus
Airy PSF against two waves of defocus:

.. plot::
   :context: close-figs

   clean_airy = imsim.simulate(time=30, psf=AiryPSF(), add_noise=False)
   clean_defocus = imsim.simulate(
       time=30, psf=DefocusPSF(DEFOCUS_2WAVE_PATH), add_noise=False
   )

   fig, ax = plt.subplots()
   _, _, (r_a, prof_a) = plot_radial_mpl(
       clean_airy, units="mas", ax=ax, show_hwhm=False
   )
   _, _, (r_d, prof_d) = plot_radial_mpl(
       clean_defocus, units="mas", ax=ax, show_hwhm=False
   )
   ax.lines[0].set_label("in-focus (Airy)")
   ax.lines[1].set_label("+2 waves defocus")
   ax.set_yscale("log")
   ax.set_xlim(0, 800)
   ax.legend()
